# MANGO FX

「リスクの前に、経験を。」Chromebook・WindowsのChrome / Edgeなど、モダンなブラウザで使う日本語のFX練習アプリです。実際の送金や金融口座への接続はありません。

## ダウンロードしたアプリを開く

1. `MANGO-FX.html` をパソコンにダウンロードします。
2. Windowsではファイルを右クリックし、「プログラムから開く」→ ChromeまたはEdgeを選びます。Chromebookでは「ファイル」アプリからダウンロードしたファイルを開きます。
3. トレード画面が表示されたら、そのまま練習を始められます。

この1ファイルに画面とプログラムが含まれるため、追加のインストールやサーバーの起動は不要です。ダウンロード後はインターネット接続なしで使用できます。

進捗は開いたブラウザに保存します。サーバー版や別の保存場所にあるHTMLファイルとは保存先が異なる場合があり、履歴は自動同期されません。同じファイルを同じブラウザで開いてください。

## Chrome / Edgeにアプリとしてインストール（PWA）

PWA版はChromebookのランチャー・Windowsのスタートメニューから専用ウィンドウで起動できます。

1. 配信用のファイルを**HTTPSのサイト**に公開し、その公開URLをChrome/Edgeで開きます。
2. ヘッダーの「オフライン対応」が表示されたら、保存完了です。表示のない小さい画面では、オンラインのまま初回読み込みを完了してください。
3. 「アプリをインストール」を押してブラウザの確認に従います。ボタンがない場合は「インストール方法」を確認するか、ブラウザのインストールメニューを使います。
4. インストール後はランチャー／スタートメニューから起動できます。初回保存後はオフラインでも売買・保存・CSV出力ができます。

ローカルのHTMLファイルを開いただけではPWAとしてインストールできません。開発用localhostではPWAを検証できますが、端末へ配布するにはHTTPSの公開URLが必要です。単一HTML版は引き続きファイルとして利用できます。

アプリ更新は自動で練習を中断しません。「新しいバージョンを使えます」の通知で「更新する」を選ぶと、保存済みデータを保持して新しい版に切り替わります。ブラウザデータを削除するとオフライン保存と取引データも失われます。

### 配信用ファイル

```sh
npm run build                 # dist/にHTTPS配信用PWAを生成
npm run test:pwa              # 通常プロファイルのChromiumでPWA要件・オフライン・更新を検証
npm run test:standalone       # 単一HTMLの通信不要な動作を検証
npm run package:download      # Python3で配布ZIPも生成
```

`dist/MANGO-FX-PWA.zip`はHTTPSサイトに配置するPWA一式、`dist/MANGO-FX.zip`は直接開く単一HTML版です。ZIP作成以外はPython不要です。PWAテストは通常の一時ブラウザプロファイルを使用します。シークレットモードではブラウザがインストールを許可しません。管理環境での`file:`表示制限のため、単一HTMLのテストは同一HTMLを通信無効状態で読み込んで検証しています。

### GitHub Pagesで公開する場合

`.github/workflows/pages.yml`は手動実行型です。このリポジトリの内容をGitHubに保存したうえで、GitHubのSettings → Pages → SourceをGitHub Actionsに設定し、Actionsの「Publish MANGO FX browser app」を手動実行します。成功後にGitHubが表示するHTTPS URLを使用してください。ワークフローを作成しただけでは公開されません。

相対パスとサブディレクトリ配信に対応しています。公開先がルートでも`/mango67A/`でも同じビルドを配置できます。Service Worker・manifest・アイコンを含め、dist内の構成を保ってください。

## 開発・起動

Node.js 22.12以上（この環境では24）、npmを使用します。

```sh
cd /workspace/mango67A
npm ci
npm run dev
```

自分のPCにコピーして開発する場合は、チェックアウトしたディレクトリで同じnpmコマンドを実行してください。Viteが表示する開発サーバーのアドレスをブラウザで開きます。APIキー、外部データベース、認証設定は不要です。

```sh
npm test            # 取引エンジンのテスト
npm run build       # TypeScript検証・配信用dist作成
npm run build:standalone # 直接開けるdist/MANGO-FX.htmlを作成
npm run preview     # ビルド結果の起動
npm run test:e2e    # Chromiumでの画面操作テスト
```

E2Eテストは標準で `/usr/bin/chromium` を使用します。別の実行ファイルを使用する場合は `CHROMIUM_PATH` を指定してください。設定ファイルのポート5173が空いている必要があります。実行中の開発サーバーがあればテストは再利用します。

## できること

- USD/JPY、EUR/JPY、GBP/JPY、EUR/USDの4通貨ペア
- ローソク足、OHLC、現在値・建玉ライン、クロスヘア、1分・5分・15分・1時間足
- 成行、指値、逆指値、買い・売り、利確・損切り
- 円建ての評価損益、必要証拠金、維持率、ロスカット
- 停止・再生、1/2/5倍速、レンジ・上昇・下降・高変動の相場シナリオ
- 建玉の個別・一括決済、注文取消、取引履歴、CSVダウンロード
- このブラウザへの自動保存、確認付きリセット、初心者向けガイド
- 狭い画面でも操作できるレスポンシブレイアウト、キーボード操作

## 計算とモデルの前提

- 初期仮想資金100万円。レバレッジ25倍。1 lot＝1万通貨、最小0.1 lot。
- 価格は生成されたシミュレーションデータです。リアルタイムの実相場ではありません。通貨ペアごとに独立したモデルを使用し、クロスレートの一致は保証しません。
- Bidは売れる価格、Askは買える価格。スプレッドは固定です（USD/JPY 0.3、EUR/JPY 0.5、GBP/JPY 1.0、EUR/USD 0.8 pips）。
- 買いはAskで入りBidで決済、売りはBidで入りAskで決済します。売買手数料・スワップ・税金は含みません。
- 円以外の損益・証拠金は、同時点のUSD/JPYで円換算します。
- 通常速度では実時間2秒で相場1分が進みます。相場はアプリを開いている間だけ進み、ブラウザのバックグラウンド制御により更新間隔が遅くなる場合があります。
- 注文判定は更新時点のBid/Askを使います。ローソク足の高値・安値は表示用で、途中のタッチ約定は再現しません。指値・逆指値・利確・損切りの約定値は判定時の実行可能価格となり、指定値と異なることがあります。
- 未約定注文では証拠金を予約しません。約定時に不足した注文は取り消され、画面に通知します。
- 維持率50%以下で全建玉を自動決済します。市場の流動性、通信遅延、実際のブローカーの約定条件は再現しません。
- 表示時刻は日本時間（JST）です。チャートは直近1,440本の1分足を保持します。

取引データは端末のlocalStorageに保存します。ブラウザのデータ削除やプライベートブラウズの終了で消える場合があります。アカウント同期や他端末への自動引継ぎはありません。必要に応じて取引履歴をCSV出力してください。

## 構成

- React / TypeScript / Vite
- `src/lib/engine.ts`: 独立した取引・相場生成エンジン
- `src/components/PriceChart.tsx`: SVGチャート
- `src/App.tsx`: 注文・建玉・履歴・保存と学習画面
- Vitestで計算を、Playwright + Chromiumでブラウザ上の操作を検証

クラウドの各タスクはすでに隔離されています。通常は既存のチェックアウトを使用し、ユーザーから明示的に依頼されない限りGit worktreeは作成しません。
