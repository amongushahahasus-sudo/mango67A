# コード・ファイル商品の商品写真

コード入りTXT・PDF・ZIPの商品に、一覧と詳細画面へ表示する商品写真を付けられます。写真は任意で、既存の商品にも追加・変更・取り外しができます。通常販売とくじ販売の両方に対応します。

## 追加設定

`shop-files.sql`、`shop-lottery.sql` を導入済みの同じSupabaseプロジェクトのSQL Editorで、[shop-product-images.sql](shop-product-images.sql) を実行してください。最後に `product_images_ready: true` が返ります。既存の商品、購入履歴、くじ履歴、管理者権限は保持します。このSQLは再実行できます。古い追加SQLを再実行する場合は、最後にこのSQLも実行してください。

## 使い方

1. 管理者で「商品管理」を開き、コード・ファイル商品を新規登録するか、登録済み商品の「編集する」を選びます。
2. 「商品写真（任意）」でJPEG・PNG・WebPを選びます。「販売するファイル」には、引き続き受け渡すTXT・PDF・ZIPを指定します。登録済みの販売ファイルを選び直す必要はありません。
3. 新規商品は「商品を登録する」、登録済み商品は「変更を保存する」を押します。一覧と詳細画面に商品写真が表示されます。

写真を変更するときは別の写真を選び、取り外すときは「商品写真を外す」を選んで保存します。写真なしでも販売できます。追加設定前は写真欄が無効ですが、従来のファイル商品は管理できます。

## 商品写真の扱い

- 商品写真は公開用です。コードや個人情報が写らない画像を選んでください。
- JPEG・PNG・WebPを読み込み、長辺960px以下のJPEGに縮小して公開します。透かしは追加しません。元の高解像度画像は保存しません。
- `shop-product-images` は公開バケットで、保存先は `{商品UUID}/{画像UUID}.jpg`、JPEG・2 MiBまでです。URLを知っている人は閲覧できます。非公開下書きの写真も秘密情報の保管場所には使えません。
- 登録済みの写真は上書きせず、新しい保存先へアップロードしてから商品へ関連付けます。関連付け中の写真を管理者が削除することはできません。取り外した写真やアップロード中断で残った未参照画像だけ、管理者が削除できます。取り外しによって、公開済みのURLや外部の保存済み画像が消えるとは限りません。
- 商品の写真を変えても、販売ファイルの内容や取得権限は変えません。コード入りファイルは引き続き非公開で、購入・当選後に管理者が承認した本人だけが取得できます。

## API

`get_reward_shop` は `productImagesReady: true` と、各商品の `productImagePath`（画像なしは `null`）を追加します。写真商品にはこの追加画像を設定できません。従来の写真プレビューはそのまま使用します。

`save_shop_product_with_image` は従来の `save_shop_product` の11引数に `p_product_image_path` を追加したAPIです。商品と画像の関連付けは同じトランザクションで保存し、管理者権限と商品の版番号を検証します。`null` は商品写真の取り外しを意味します。従来の保存APIは画像の関連付けを保持します。

`npm test` に含まれるPostgreSQLテストで、公開画像と非公開ファイルの分離、権限、関連付けの追加・交換・削除、競合、SQLの再実行を検証します。
